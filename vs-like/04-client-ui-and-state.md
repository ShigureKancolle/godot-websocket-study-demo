# 04：客户端镜像与 UI

## 目标

消费服务端 Run 镜像，提供局内 HUD、升级选择、死亡结算和返回主界面；客户端不拥有或推导权威状态。

## 步骤

1. 扩展只读镜像以显示时间、波次、生命、等级、经验、玩家和敌人表现状态。
2. 单人暂停时显示三选一并禁止战斗表现继续推进；多人模式显示候选但允许世界继续更新，选择请求交给服务端。
3. 显示经验球、死亡反馈；HUD 绿色能量槽实际显示 experience/next_experience，并显示仅含存活时间/波次/击杀/伤害的结算页。
4. 返回主界面后释放场景、订阅、计时器和本局镜像；再次开始时等待新 Run 快照。

## 依赖与验收

依赖任务 01，表现可与服务端和配置开发并行。服务端拒绝选择时 UI 不错误应用奖励；单人/多人视觉状态与服务器一致；重开无旧数据。
