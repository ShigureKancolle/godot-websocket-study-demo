# 05：联调与端到端验收

## 依赖

等待任务 02、03、04 完成；以任务 01 的契约和总方案为验收基线。

## 场景清单

1. 单人：进入 Run、持续移动、击杀、经验球吸收、升级时全局暂停，选奖励后恢复。
2. 双人：一人升级时另一人仍可移动、攻击和受伤；升级队列按玩家隔离。
3. 拉脱：将敌人带到 1500px 外，确认原实体、血量、属性、归属和统计不变；返程到 1200px 内恢复，目标失效时改绑或冻结。
4. 结算：玩家死亡、全员死亡、四项统计、返回主界面、重新开始。
5. 异常：掉线、重复选择、过期请求、非法玩家 ID、暂停中加入和网络乱序。

## 验收标准

服务端日志/快照与客户端显示一致；协议方向和状态校验通过；无残留实体、计时器、经验球、奖励队列或镜像。配置仅从 shared_config 同步，协议生成物和文档索引保持一致。记录无法自动化验证的项目并安排实机复测。
