# 02：服务端生存循环

## 目标

在已批准的 Run/协议模型上实现服务端权威的刷怪、战斗结算、经验球、牵引返程、升级、单多人生存规则、死亡和清理。

## 核心步骤

1. 按持续预算生成敌人；生成时固化时间/等级倍率。
2. 实现敌人目标绑定、`normal`/`returning`/冻结状态迁移。超过 1500px 只停止普通战斗 AI，保留实体并直线返程；回到 1200px 内恢复。
3. 结算攻击命中、死亡、经验球飞行和到达玩家后的经验。
4. 实现 15 秒保底经验、升级阈值、候选生成、多人待选队列和单人全局暂停。
5. 统计波次、存活时间、击杀和伤害；全员死亡后广播结算并销毁所有 Run 子状态。

## 依赖与验收

依赖任务 01，可与任务 03 并行。验收包括返程不重建且不重置属性、目标失效改绑/冻结、单人暂停所有相关 tick、多人不暂停、经验只在球到达时增加、重开无残留。
